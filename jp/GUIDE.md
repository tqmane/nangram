# Nangram ユーザーガイド

[English User Guide](../en/GUIDE.md) | [ドキュメント一覧](README.md) | [公式リリース](https://github.com/tqmane/nangram/releases) | [サポート Discord](https://discord.gg/zJBrCaf6dz)

本ガイドでは、**Nangram** の導入手順、基本機能、各機能の仕様、データ管理、トラブルシューティングについて解説します。

> [!NOTE]
> Nangram は Instagram および Meta とは無関係に開発されている独立した Android 向けカスタマイズモジュールです。Meta 社や Instagram 公式との提携・承認関係はありません。

---

## 1. 動作要件と互換性

導入を開始する前に、お使いの環境が以下の前提条件を満たしているか確認してください。

* **フレームワーク要件**: セットアップの必須要件として **libxposed API 102** に対応したモジュール環境が必要です。旧来の環境では Nangram を読み込むことができません。
* **モジュールマネージャー**: アプリケーション単位で動作対象（スコープ）を指定できる互換マネージャーを使用してください。すべてのマネージャーやパッチツールが動作するわけではありません。
* **パッチ組み込み型環境**: モジュールを APK に直接組み込むパッチ環境をご利用の場合、更新ごとにマネージャーの手順に沿ってパッチの再ビルドと再適用を行ってください。
* **対応Instagramバージョン**: `453.0.0.0.45`。更新情報はリリースノートをご確認ください。
* **署名鍵とデータ**: アプリの更新には同一の署名鍵で署名された APK が必要です。ローカルデータは各アプリごとに独立して保存されています。Nangram をアンインストールすると Nangram 側のデータが削除され、Instagram をアンインストールすると Instagram 側に保存されたデータが削除されます。安易にアンインストールせず、必ず事前に重要なデータをバックアップし、署名鍵を確認してください。

## 2. インストールと初期設定

以下の手順に沿ってセットアップを行ってください。

1. **モジュール APK のインストール**: [GitHub Releases](https://github.com/tqmane/nangram/releases) でメンテナーから公開された公式の署名済み APK を入手し、Android のパッケージインストーラーで端末にインストールします。
2. **モジュールの有効化とスコープ設定**: ご利用のモジュールマネージャーを開き、一覧から Nangram を有効化して、対象アプリのスコープに **Instagram** を選択します。
3. **Instagram の再起動**: Android の端末設定（`設定 > アプリ > Instagram`）から「強制停止」を実行した上で、Instagram アプリを起動します。
4. **初回準備の待機**: モジュールを有効化または更新した直後の初回起動時は、初期設定の準備が完了するまで少しお待ちください。
5. **アプリ内設定の表示**: Instagram 画面下部のナビゲーションバーにある **「ホーム」タブを長押し** すると、Nangram の設定画面が表示されます。

## 3. コンパニオンダッシュボードと設定の同期

端末のランチャーから Nangram のアイコンをタップすると、直接コンパニオンダッシュボードが開きます。

### 主な画面機能
* **接続ステータス表示**: Instagram との通信状態を表示します。未接続と表示される場合は、「Instagram を開く」ボタンをタップして Instagram を起動してください。
* **設定項目の検索**: 機能名、説明文、内部の設定キーから目的の設定を検索できます。
* **言語連動ナビゲーション**: アプリ内からドキュメントを開く際、端末の言語設定ではなく、アプリの現在の表示言語に基づいて案内されます（日本語表示なら `jp`、それ以外の言語では `en`）。

### 「よく使う設定」のカスタマイズ
ダッシュボード上に、頻繁に利用する設定カードを最大6件まで配置できます。

1. **表示する設定を選択** をタップすると、設定選択画面（**表示設定の選択**）が開きます。
2. 検索を活用しながら、チェックボックスで最大6件まで選択します（現在の選択件数が表示されます）。
3. **選択を保存** をタップして変更を反映します。破棄する場合は **キャンセル** をタップします。

> [!IMPORTANT]
> 「よく使う設定」での選択はダッシュボードの表示ショートカットを変更するものであり、各機能自体の有効・無効を切り替えるものではありません。

### 設定の同期仕様
コンパニオンと接続中は設定が同期されますが、一部の機能は反映に Instagram の再起動が必要です。接続できない場合は Instagram を起動し、モジュールの有効化とスコープ指定を確認してください。コンパニオンは設定の検索、ショートカット登録、接続確認、ヘルプの参照を行います。メディア保存管理、メッセージ履歴、バックアップ等の各種ツールは、Instagram 内の Nangram 設定から利用します。

## 4. 機能グループと詳細仕様

各機能は必要に応じて個別に有効化できます。なお、Instagram のバージョン、アカウントの状態、端末仕様によって一部機能が利用できない場合があります。

### フィード・操作制御
* **フィードフィルタリング**: スポンサー広告、おすすめ投稿、リール動画などをタイムライン上で非表示化します。
* **テキストコピー**: 投稿キャプション、コメント、プロフィール自己紹介文をクリップボードにコピーできます。
* **写真ズーム**: 投稿写真を長押し操作で拡大表示できます。
* **誤操作防止確認**: いいね、フォロー、コメント投稿などの操作時に確認ダイアログを表示し、誤タップを防止します。

### ストーリー・アーカイブ管理
* **再生制御とステルス閲覧**: ストーリーの再生コントロールが利用できるほか、対応画面で相手に閲覧通知（足跡）を残さずに閲覧可能です（機能が有効な場合）。
* **閲覧保存と自投稿アーカイブの違い**:
  * *閲覧ストーリーの保存*: 閲覧中の他ユーザーのストーリーメディアを端末に保存する機能です。
  * *自投稿ストーリーアーカイブ*: 自身が投稿したストーリーおよびその閲覧者リスト（足跡）をローカルに保存する機能です。本機能を有効にする前に期限切れとなった過去のストーリーは取得できません。
* **フォアグラウンド実行制限**: ストーリーの保存や巡回処理は、Instagram が現在のアカウントでフォアグラウンド起動している間のみ動作します。バックグラウンドでのスケジュール実行は行われません。

### ダイレクトメッセージ（DM）とプライバシー
* **既読送信の防止**: 受信したメッセージを開封しても既読通知の送信を抑止します（機能が有効で対応している画面のみ）。
* **手動既読送信**: 手動既読ボタンを押すとサーバーへ既読通知を送信します（通信状態などにより送信結果は変動し、即時反映が保証されるものではありません）。
* **メッセージ履歴保持**: 受信したメッセージを端末内に記録し、相手が送信取消したメッセージもローカル履歴として保持します（機能が有効な間に受信・観測されたデータのみが対象です。有効化前にサーバー上で削除されたメッセージを復元することはできません）。
* **ローカルロック**: 会話一覧や Nangram 設定画面を生体認証や暗証番号で保護します。このロックは端末上のローカル画面のみを保護するものであり、Instagram アカウント自体のセキュリティを変更するものではありません。

### メディア保存とライブラリ管理
* **保存先の指定**: Android 標準のストレージピッカーを使用して、メディアの保存先フォルダを設定します。
* **画面内ダウンロード**: 投稿、リール、ストーリー画面に表示される専用ボタンやメニューから保存を実行します。
* **保存キュー**: ダウンロードの進捗状況や失敗状況を表示し、キャンセルや再試行操作が可能です。
* **期限切れ URL への対応**: メディアの URL 期限切れで失敗した場合は、Instagram 上で元の投稿を再度開いて URL を更新してください。すでにサーバーから削除されたメディアの救済は保証されません。
* **プロフィール一括保存**: ユーザープロフィールから、プリセット件数、指定件数（カスタム件数）、全件の一括保存を実行できます。一括保存は順次処理されます。通信切断や容量不足などで途中で停止した場合でも、すでにキューに追加された処理は維持されます。
* **メディアライブラリ**: 保存したファイルをファイル名検索、種類別フィルター、フォルダ分け、お気に入り登録して管理できます。外部ストレージやギャラリーへ書き出したファイルは、ライブラリ内の整理操作の影響を受けません。

### プロフィールアナライザーとLiquid Glass
Instagram内のNangram設定から「プロフィールアナライザー」を開き、スキャンを実行します。相互フォロー、フォローバックされていない相手、自分がフォローしていないフォロワーを集計できます。初回の完了したスキャンが比較の基準となり、次回以降に変化を表示します。スキャンの間隔は15分以上、フォロワーとフォロー中の合計が13,000人未満のアカウントが対象です。

フローティングのガラス調ナビゲーションは、Nangramのインターフェース設定で「すりガラス風タブバー」を有効にすると使えます。Instagramのタブアイコンと操作を引き継ぎます。描画の見え方は端末によって異なります。

### プロフィールウォッチリストと外観設定
* **ウォッチリスト**: 登録したアカウントの自己紹介、アイコン、フォロワー数などの変更を監視します（Instagram 起動中のみ）。
* **外観と設定プロファイル**: テーマカラーの変更や、アカウントごとの設定プロファイル作成が可能です。アカウントを切り替えた際は、適用されているアクティブなプロファイルをご確認ください。

## 5. ストレージ管理・データ保持・バックアップ

ローカルデータの保存上限やバックアップに関する仕様は以下の通りです。

* **サイズ上限と保持期間**: ダウンロードするファイルサイズの上限やデータの保持日数を設定できます（`0` はサイズ無制限、無期限保持）。
* **容量上限到達時の挙動**: 端末容量や指定の上限に達した場合、**新規の保存を停止**します。空き容量を作るために既存のファイルを自動削除することはありません。
* **保持期限による自動整理**: 設定した保持期限を過ぎた古いローカルデータは自動的に整理されます（お気に入り保護オプションあり）。
* **バックアップの作成**: Android のファイル選択画面から、設定や端末内の記録を ZIP ファイルとして書き出せます。メディアを含めるかどうかを選択できます。**バックアップ ZIP は暗号化されていません**ので、保管場所には十分ご注意ください。
* **バックアップの内容と除外項目**: メディアを含めるかどうかによって、バックアップの内容が変わります。設定単体の JSON ファイルは設定情報のみを含み、完全なバックアップではありません。パスワード、ログイン情報（セッショントークン）、画面ロックの暗証番号情報は一切含まれません。
* **ローカル履歴の記録条件**: メッセージ履歴やストーリー情報は、該当機能が有効で実際にデータを受信・表示した期間のみ記録されます。機能を有効にする前の削除済みデータや過去のストーリーは復元できません。
* **復元手順**: ファイルピッカーからバックアップ ZIP を選択すると整合性検証が行われ、**次回 Instagram 起動時** に適用されます。端末全体の再起動は不要です。

## 6. トラブルシューティングとサポート

問題が発生した場合は、以下の対処方法を確認してください。

| 症状 | 原因の可能性 | 対処方法 |
| :--- | :--- | :--- |
| **コンパニオンが未接続になる** | モジュール未有効化またはスコープ未設定 | 1. マネージャーで Nangram が有効か確認する。<br>2. スコープに Instagram が含まれているか確認する。<br>3. Instagram を強制停止して再起動する。<br>4. マネージャーが libxposed API 102 に対応しているか確認する。 |
| **設定が反映されない** | プロセスの再起動待ちまたは未対応バージョン | 1. Instagram を強制停止して再起動する（一部の設定は反映に再起動が必要です）。<br>2. 動作対象の Instagram バージョンか確認する。 |
| **メディア保存が失敗する** | 権限不足、容量不足、または URL 期限切れ | 1. 保存先フォルダの書き込み権限を確認する。<br>2. 端末の空き容量を確認する。<br>3. Instagram で対象の投稿を再度開いて URL を更新する。 |
| **アップデートのインストールに失敗する** | パッケージ署名鍵の不一致 | 1. 同一の署名鍵でビルドされた APK を使用する。<br>2. アンインストール前に必ず手動バックアップを作成する。<br>3. パッチ適用環境の場合は、マネージャーの手順に従って再適用する。 |
