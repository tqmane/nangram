# Nangram ドキュメント (日本語)

**Nangram** の公式ドキュメントへようこそ。Nangram は、Android 版 Instagram 向けに開発された独立したカスタマイズモジュールおよびコンパニオンアプリです。

> [!NOTE]
> Nangram は独立したプロジェクトであり、Instagram または Meta との提携、承認、関係は一切ありません。

Instagramのアイコンと操作を引き継ぐ、半透明のフローティング下部バー。Nangramのインターフェース設定から有効にすると、白黒を基調としたガラス調の表示に切り替わります。

### プロフィールアナライザー

相互フォロー、フォローバックされていない相手、自分がフォローしていないフォロワーを確認できます。取得したリストを端末内に保存し、次回以降の結果と比較して変化を把握。パスワードの再入力は不要で、初回の完了したスキャンが比較の基準になります。

<img src="../assets/screenshots/en/profile-analyzer.png" alt="tqmane78_のプロフィールアナライザー集計画面（英語表示）" width="320">

### Instagramとつながるコンパニオン

設定を検索し、よく使う設定を最大6件までホームに配置。両アプリが動作している間、対応する設定を現在のアカウント・設定プロファイルに合わせて双方向に同期します。一部の変更はInstagramの再起動後に反映されます。

<img src="../assets/screenshots/en/companion.png" alt="接続済みのNangramコンパニオン（英語表示）" width="320">

保存先の権限、ロック情報、保存した画像・動画や履歴はアプリ間でコピーしません。アナライザーは取得したリストを比較する機能で、プロフィールの訪問者やブロックした相手を特定する機能ではありません。

## 概要

Nangram は、以下の2つの要素で構成されています：
1. **Instagram 向けモジュール**: Instagram アプリ内で動作し、表示制御、プライバシー保護、メディア保存などの機能を提供します。
2. **コンパニオンアプリ**: アプリ一覧から直接起動できるダッシュボードです。設定の検索、よく使う設定のショートカット登録、接続状態の確認、ヘルプの参照を行えます。（メディア保存管理、メッセージ履歴、バックアップ等の各種ツールは、Instagram 内の Nangram 設定から利用します。）

本リポジトリはドキュメント専用であり、アプリのソースコードは非公開です。

### 主な機能

対応する各機能を有効にすることで、以下の操作が可能です：

* **フィードと操作**: 広告やおすすめ投稿の非表示、キャプションやコメントのコピー、写真の拡大、いいねやフォロー前の確認ダイアログ。
* **ストーリー**: 再生コントロール、対応画面で閲覧通知を送らない閲覧、自身の投稿ストーリーや閲覧者リストのローカル保存。
* **ダイレクトメッセージ（DM）**: 既読を付けないメッセージ確認、手動での既読送信、受信したメッセージ履歴のローカル保持、画面ロックによる保護。
* **メディア保存とライブラリ**: 投稿・リール・ストーリーの指定フォルダ保存、進行状況や再試行を管理できる保存キュー、指定件数のプロフィール一括保存、オフラインライブラリでの整理。
* **プロフィールウォッチリスト**: Instagram 起動中に、登録プロフィールのアイコン、自己紹介、フォロワー数などの変更を確認。
* **外観・設定**: テーマの変更や、アカウントごとの設定プロファイルの切り替え。

## 動作要件と互換性

* **フレームワーク要件**: セットアップの必須要件として **libxposed API 102** に対応した環境が必要です。
* **対応Instagramバージョン**: `453.0.0.0.45`。更新情報はリリースノートをご確認ください。
* **パッチ適用環境での注意**: モジュールを APK に組み込むパッチ環境をご利用の場合、更新ごとにマネージャーの手順に沿って再パッチと再署名を行ってください。すべてのパッチマネージャーでの動作を保証するものではありません。
* **署名鍵とデータ**: アプリの更新には同一の署名鍵が必要です。ローカルデータは各アプリごとに保存されています。Nangram をアンインストールすると Nangram 側のデータが消去され、Instagram をアンインストールすると Instagram 側に保存されたデータが消去されます。安易にアンインストールせず、必ず重要なデータをバックアップし、署名鍵を確認してください。
