# Nangram

Nangram is an independent Android customization module for Instagram, accompanied by a companion dashboard. It provides options for interface behavior, privacy settings, media saving, and local history.

> [!NOTE]
> Nangram is an independent project and is not affiliated with, endorsed by, or associated with Instagram or Meta.
